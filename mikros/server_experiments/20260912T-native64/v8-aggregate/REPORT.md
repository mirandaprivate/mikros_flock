# v8：首轮聚合优化与 Flock-128 的同 binary 比较

按本批独立 N30 的 8 次测量，推荐显式选择 **pairreuse** 作为较稳妥的工程选项：它每次均快于同组 basisreuse 和 Flock-128。Joint 中位数更低，但均值 75.649 ms 高于 Pair 的 64.410 ms，最大值 164.522 ms，高于 Pair 的 74.296 ms。保留所有长尾样本；这不证明跨机器稳定性或绝对最快，也不自动改变默认内核。

N=2^30 的 results 组：pairreuse prover 中位数 66.270 ms，basisreuse 基线 91.747 ms；两中位数之比 0.722。同输入配对比值中位数 0.700，8/8 次候选较快。prover 均值分别为 64.410 / 93.911 ms。

同组 Flock-128 prover 中位数 89.543 ms；候选/Flock 的两中位数之比 0.740，配对比值中位数 0.736，候选较快 8/8 次。与 Flock 的全部差距不能自动归因于新增聚合优化，应同时看同组 basisreuse 对照。

N=2^30 的 results 组：jointreuse prover 中位数 61.235 ms，basisreuse 基线 91.747 ms；两中位数之比 0.667。同输入配对比值中位数 0.649，7/8 次候选较快。prover 均值分别为 75.649 / 93.911 ms。

同组 Flock-128 prover 中位数 89.543 ms；候选/Flock 的两中位数之比 0.684，配对比值中位数 0.707，候选较快 7/8 次。与 Flock 的全部差距不能自动归因于新增聚合优化，应同时看同组 basisreuse 对照。

Joint/Pair：两中位数之比 0.924，均值之比 1.174；同输入配对比值中位数 0.942，Joint 较快 5/8 次。样本范围分别为 [54.425, 164.522] / [48.649, 74.296] ms。

两者中位数与均值的排序相反，长尾记录仍全部保留；不能只按较低中位数判定整体最快。

`+nightly-2026-03-21`、`target-cpu=native`，GFNI/AVX512 及所需 ISA 特性已核验。各组使用同一冻结源码与 executable，分别统计 N26 筛选和独立 N30 测量。

## 实现与协议边界

`basisreuse` 保留 v6 基线。split/half 改变首轮消费方式；pair 改变首轮 A/B continuation 展开；affine 在 split 基础上优化 H 部分；joint 组合 pair 与 affine。这些路径保持 Batch 坐标转换与其他协议阶段一致，不混入 v7 的额外 A/B 打包优化。候选名称与本文数值都以实际 systems 列表为准。

GF256 嵌入、扩域数学基、采样点、商多项式、挑战域、证明格式保持一致；所有 Mikros 内核必须对同输入给出相同证明摘要。代码或汇编中的寄存器与访存变化不能直接当作实测 cache miss、DRAM 带宽或端到端加速。

比较边界为 κ=128 的单变量 PIOP，终止于直接 packed-opening claims，不含额外 2κ 列聚合、PCS 或承诺打开。Flock 使用 skip-7，同压缩比 128；BLAKE3、关闭 grinding，不作相同安全等级声明。

## 正式端到端计时

每系统每维度一次 warmup，随后按 run 轮转，各位置出现次数相同；各 reuse 模式独立保留 scratch，动态值重新计算。Flock 使用生产内存池。固定表首次初始化未扣除；进程中的各系统 warmup 不等于各自独立冷启动。
